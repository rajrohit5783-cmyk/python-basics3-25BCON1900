# Student Class in Python 🐍

A simple Python program demonstrating how to create a class and object to store and display student information.

## 📌 Project Description

This project demonstrates the basic use of **classes and objects in Python**.

The program defines a `Student` class with three attributes: `name`, `roll`, and `marks`. A `Student` object is then created with predefined information and the details are displayed using `print()` statements.

## ✨ Features

* Demonstrates Python classes and objects
* Stores student name, roll number, and marks
* Uses a class constructor (`__init__`)
* Creates a `Student` object
* Displays student information
* Uses no external libraries

## 🛠️ Installation

No additional packages or dependencies are required.

Make sure **Python 3.x** is installed on your system.

Check your Python version:

```bash
python --version
```

Or:

```bash
python3 --version
```

## 📋 Requirements

* Python 3.x
* No external Python packages are required

## 🚀 Usage

Run the program from the project directory:

```bash
python struct.py
```

Or:

```bash
python3 struct.py
```

The program creates a `Student` object using predefined student information and displays the stored details.

## 💡 Example

### Student Information

The current program uses:

```python
name = "Rahul"
roll = 101
marks = 87.5
```

### Output

```text
Name: Rahul
Roll: 101
Marks: 87.5
```
